LANGKAH 1: RINGKASAN & ANALISIS KODE REFERENSI AWAL
================================================================================

Proyek ini diawali dari file referensi "Laporan Rumah Tahfidz.html" yang merupakan
aplikasi satu halaman (SPA) berbasis JavaScript murni dan localStorage.

Temuan Audit Masalah pada Kode Lama:
1. Penyimpanan Lokal: Data hanya tersimpan di browser satu perangkat. Jika petugas
   menggunakan smartphone dan admin menggunakan laptop, data tidak terhubung.
2. Keamanan Rendah: Otentikasi admin hanya menggunakan validasi PIN JavaScript
   (PIN="admin123") yang tersimpan telanjang dan mudah dimanipulasi melalui console.
3. Integritas Relasi Lemah: Data siswa dan petugas pada laporan hanya berupa teks string,
   bukan ID relasional. Jika ada siswa dengan nama sama atau diedit, riwayat menjadi rancu.
4. Pelanggaran Standar Desain AntiSlop: Menggunakan karakter em dash (—) pada label teks,
   tidak memiliki penanganan aksesibilitas keyboard (Escape pada modal), dan tidak ada
   validasi numerik nilai yang ketat.

Solusi:
Mengembangkan ulang menjadi aplikasi Full-Stack terpusat berbasis Laravel 12 dengan
arsitektur MVC, database MySQL relasional, sistem otentikasi sesi aman, dan tampilan
Clean Clinical Dashboard dengan sentuhan Islamic Modern.

LANGKAH 5: PEMBUATAN STRUKTUR DATABASE (MIGRASI & MODEL ELOQUENT)
================================================================================

Membuat Model, Migration, Factory, dan Seeder:
$ php artisan make:model Petugas -mfs
$ php artisan make:model Siswa -mfs
$ php artisan make:model LaporanSetoran -mfs
$ php artisan make:migration add_role_to_users_table --table=users

Penjelasan Struktur Tabel:
1. Tabel "petugas":
   - id: Primary Key (bigint unsigned)
   - nama: string
   - is_active: boolean (default true)
   - timestamps

2. Tabel "siswas":
   - id: Primary Key (bigint unsigned)
   - nama: string
   - kelas: string (contoh: "X-1", "XI-2")
   - jurusan: string nullable ("MIPA", "IPS", "Keagamaan", "Bahasa")
   - tahun_ajaran: string (contoh: "2026/2027")
   - timestamps

3. Tabel "laporan_setorans":
   - id: Primary Key (bigint unsigned)
   - waktu_setoran: datetime
   - petugas_id: foreignId constrained to 'petugas', nullOnDelete
   - nama_petugas: string (snapshot nama petugas)
   - siswa_id: foreignId constrained to 'siswas', nullOnDelete
   - nama_siswa: string (snapshot nama siswa)
   - kelas: string
   - jurusan: string nullable
   - tahun_ajaran: string
   - kategori: string ("Ziyadah" atau "Murojaah")
   - surah: string (contoh: "1. Al-Fatihah", "78. An-Naba")
   - ayat: string (contoh: "1-10")
   - nilai: string (skor 0-100)
   - catatan: text nullable
   - timestamps

4. Modifikasi Tabel "users":
   - Menambahkan kolom "role" string default 'petugas'.

Menjalankan migrasi database:
$ php artisan migrate
